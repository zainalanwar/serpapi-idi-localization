# Contributing

Start with a small correction or a reproducible learner problem. Match each
parameter and JSON field to the official documentation linked in the guide.
Add a test when changing behavior. Run the unit suite before proposing a change.

Describe expected and actual results, the tested environment and whether a test
was offline or live. Redact credentials and private customer data. Label synthetic
examples, AI assistance, and unverified claims accurately. Do not submit raw keys.
